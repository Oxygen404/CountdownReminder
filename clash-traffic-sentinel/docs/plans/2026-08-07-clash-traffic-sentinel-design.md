# Clash 流量哨兵设计

## 目标

创建一个只驻留于 Windows 通知区域的代理流量审计工具。程序没有普通主窗口、不占用任务栏；左键点击托盘图标时，在当前屏幕右下角显示悬浮卡片。它只统计 Clash Verge 中真正经过代理节点的流量，排除 `DIRECT`、局域网及未进入 Clash 的连接。

## 采集与归属

程序通过 Clash Verge Rev 为 Mihomo 创建的 `\\.\pipe\verge-mihomo` 命名管道读取 `/connections`，不修改 Clash 配置、不开放控制端口，也不需要管理员权限。每个连接使用 Mihomo 提供的进程、进程路径、域名、代理链和累计上传/下载计数；轮询差值按应用与域名归属。首次启动把已有连接作为基线，只从工具运行后开始累计。Clash 未启动、切换配置或重启时自动等待并重连。

## 本地持久化

统计写入 EXE 同目录的 `traffic-data.db`。数据库不存在时自动创建，按本地自然日永久保存应用—域名聚合数据；短期分钟桶仅用于三分钟异常检测。数据库、日志边车文件、构建目录全部由 `.gitignore` 排除。程序只在内存中读取 Clash 密钥，密钥不写入数据库、日志或错误信息。SQL 全部使用参数绑定。

## 交互与提醒

悬浮卡片提供“今天 / 本周”和“应用 / 域名”切换；点击应用进入该应用的域名排行。卡片显示代理总量、上传/下载、当前速度、活跃连接和采集状态。任意应用在滚动三分钟内达到 200 MB 时提醒，并对该应用冷却 30 分钟；当天代理流量达到 1 GB 后，每增加 1 GB 再提醒。阈值和冷却时间可在卡片设置页调整，提醒进度持久化以避免重启后重复弹出。

## 容错与验证

命名管道响应设置大小上限，只接受本机固定管道与 Clash 配置中的凭据。格式变化、认证失败、数据库异常和 Clash 离线均转为不含敏感信息的状态提示，后台继续重试。交付前验证连接解析、代理筛选、增量计算、数据库聚合、提醒里程碑、单实例、实际 Mihomo 连接以及 DPI 下的悬浮卡片截图。
