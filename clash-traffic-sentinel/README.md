# Clash 流量哨兵

只统计真正经过 Clash Verge 代理节点的流量，并按应用和域名永久保存在本机。

## 使用

运行 `Clash 流量哨兵.exe` 后不会出现普通窗口，也不会占用任务栏。

- 左键点击托盘图标：显示或收起右下角流量卡片
- “今天 / 本周”：切换统计周期
- “应用 / 域名”：切换排行维度
- 点击应用：查看该应用访问的域名及流量
- 右键托盘图标：显示卡片、开机启动、打开数据目录或退出

默认提醒规则：单个应用三分钟达到 200 MB；当天代理总量达到 1 GB，之后每增加 1 GB 再提醒。应用提醒冷却 30 分钟。

## 数据与隐私

数据文件是 EXE 同目录的 `traffic-data.db`，首次启动时自动创建。它不会上传，也已从 Git 中排除。工具只读取 Clash Verge 的本地命名管道和本地配置，不抓包、不解密 HTTPS、不修改 Clash 设置。

历史明细从工具首次运行开始记录，无法补算启用前的应用或域名流量。

Mihomo 的连接接口提供当前活跃连接快照。工具每 500 毫秒采样以尽量保留短连接；在两个采样点之间建立并结束的极短连接可能无法归属到具体应用或域名，因此明细可能与服务商计费存在少量差异。

## 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

使用 Windows 自带的 .NET Framework 4.x 编译器和 `winsqlite3.dll`，不需要安装 SDK 或第三方运行库。
