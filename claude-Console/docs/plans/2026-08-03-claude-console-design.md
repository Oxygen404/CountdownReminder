# Claude Console 悬浮额度卡片设计

## 目标

创建一个只驻留于 Windows 通知区域的 Claude Code 额度查看工具。启动时不显示普通窗口、不占用任务栏；左键单击托盘图标后，在当前显示器任务栏上方弹出无边框悬浮卡片，失去焦点后自动收起。

## 交互与视觉

- 以“本周剩余”为第一视觉层级，显示剩余百分比、进度条和重置时间。
- 第二层展示 5 小时会话额度，方便判断近期是否需要降低使用强度。
- 顶部提供刷新按钮；底部显示最近更新时间和五分钟自动刷新说明。
- 右键托盘菜单提供显示/收起、立即刷新、开机启动和退出。
- 使用暖白背景、Claude 珊瑚橙、青绿色辅助色以及克制阴影，保持清爽且适合长期驻留。

## 数据与安全

应用只从 `%USERPROFILE%\.claude\.credentials.json` 在内存中读取 Claude Code 的 OAuth 访问令牌，并通过 HTTPS 请求 Claude Code 使用的额度接口。令牌不写入应用配置、不输出到日志、不出现在错误信息中。令牌临近过期或接口返回未授权时，应用静默运行本机 `claude auth status --json`，由官方 CLI 完成刷新，然后重新读取凭据；应用自身不改写凭据文件。

## 容错与验证

断网、未登录、CLI 不存在或接口发生变化时，卡片显示不包含敏感信息的错误说明和重试入口。构建包含解析单元测试、真实额度读取测试、单实例测试和实际悬浮窗截图检查。最终交付源码、构建脚本与单文件 EXE。
